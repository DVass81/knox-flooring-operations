- Gross profit dollars
- Gross margin percentage
- Estimated install hours

Add a simulated AI recommendation section based on rules.

AI should provide:
- Suggested waste factor
- Install complexity rating
- Profitability warning
- Material ordering warning
- Schedule recommendation
- Risk areas
- Crew recommendation
- Customer-facing project summary

Example rule logic:
- Tile jobs have higher labor and longer duration
- Hardwood jobs require acclimation warning
- Large LVP jobs over 1,200 sq ft may require 2-3 crew members
- Carpet jobs usually install faster
- Jobs in Sevierville or Lenoir City may need travel time note
- If material is not received but job is scheduled, show warning
- If margin is below 35%, show profitability warning
- If waste factor is below 7%, show risk warning
